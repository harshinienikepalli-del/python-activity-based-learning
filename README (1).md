## About This Project
This repository contains 10 simple Python case studies for a first-year programming assignment. The programs use basic Python concepts such as input/output, variables, conditions, loops, lists, nested lists and tuples.

## Programs
1. `attendance.py` – Student Attendance Calculator
2. `exam_result.py` – Examination Result and Grace-Mark Validation
3. `shopping_budget.py` – Multi-Product Shopping Budget Constraint
4. `traffic_penalty.py` – Traffic Violation Penalty Calculator
5. `food_waste.py` – Food Waste Monitoring System
6. `canteen.py` – Smart Canteen Order and Stock Management
7. `retail_order.py` – Retail Order Dispatch and Return Analysis
8. `festival.py` – Campus Festival Registration and Financial Audit
9. `hospital.py` – Hospital Resource Allocation and Capacity Monitoring
10. `incident.py` – Smart Campus Incident and Maintenance Prioritization

## How to Run
1. Install Python and open this project folder in VS Code.
2. Open the terminal.
3. Run a program, for example:

```bash
python attendance.py
```

4. Enter the requested values and view the output.

**Note:** The fine amounts, grace marks, discount, resource requirements and priority rules are sample rules for this assignment, not official policies.
